# Wallet

An interactive 3D product experience for a minimalist wallet concept.

The project combines product design, 3D modeling, and front-end development to create an immersive way of presenting a physical product through the web.

## Overview

The experience allows users to explore a 3D wallet through an interactive interface, combining product presentation with smooth animations and camera movement.

The goal was to experiment with how 3D can be integrated into a web interface to make a product feel more tangible and engaging.

## Role

**Designer & Front-end Developer**

I designed the experience, created the 3D assets, and developed the interactive web interface.

## Built With

* React
* React Three Fiber
* Three.js
* Drei
* Sass
* Blender

## 3D Experience

The wallet is presented as an interactive 3D model using **React Three Fiber** and **Three.js**.

The project explores:

* 3D product visualization
* Camera interaction
* Scroll-based animation
* Product positioning and composition
* Web-based 3D experiences
* Responsive presentation

## Design Focus

The visual direction focuses on **minimalism, product presentation, and interaction**, using 3D as the main visual element rather than relying on traditional product photography.
